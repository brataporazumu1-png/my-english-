# Как опубликовать My English Dictionary как PWA

Приложению нужен обычный статический HTTPS-хостинг. Серверная часть и база данных не требуются.

## Самый простой вариант: Netlify Drop

1. Распакуйте архив `my-english-pwa-ready.zip`.
2. Откройте https://app.netlify.com/drop
3. Перетащите папку с файлами сайта в окно браузера.
4. Netlify выдаст HTTPS-ссылку вида `https://...netlify.app`.
5. Откройте эту ссылку в Safari на iPhone.
6. Нажмите кнопку «Поделиться».
7. Выберите «На экран Домой».
8. Включите «Открыть как веб-приложение».
9. Нажмите «Добавить».

После первого полного открытия приложение кэширует интерфейс и встроенный словарь для офлайн-работы. Ваши уроки и прогресс хранятся локально в браузере на конкретном устройстве.

## GitHub Pages

Можно также загрузить все файлы в корень репозитория GitHub и включить Settings → Pages → Deploy from a branch. Относительные пути уже настроены, поэтому приложение работает и из подпапки GitHub Pages.

## Важно для iPhone

- Используйте именно Safari для добавления на домашний экран.
- Сайт должен открываться по HTTPS.
- Не очищайте данные Safari для этого сайта, если хотите сохранить локальные уроки.
- Для резервной копии используйте «Настройки → Экспортировать».
