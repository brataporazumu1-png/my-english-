# My English Dictionary — офлайн-база 15 000 частотных слов

## Что умеет эта версия
- Нейросеть, серверные функции и API полностью удалены.
- В приложение встроен файл `dictionary-15000.json`.
- В базе ровно 15 000 уникальных английских словоформ, расположенных по частотности.
- Для каждой статьи сохранено до 10 русских вариантов перевода.
- Проверка выполняется прямо на телефоне и работает без интернета.
- Сомнительный перевод не заменяется автоматически: приложение показывает варианты перед сохранением.
- Слова и фразы, которых нет в базе, можно сохранить без изменений.

## Как проходит проверка
При вводе:

`house — лошадь`

приложение покажет расхождение и предложит варианты, среди которых будет:

`дом`

Нужно нажать подходящий вариант и затем «Сохранить проверенный урок».

Такой порядок выбран специально: многие английские слова многозначны, поэтому словарь не должен молча заменять допустимый перевод на другое значение.

## Ограничения
- База проверяет отдельные английские слова.
- Фразы и предложения сохраняются без автоматической проверки.
- Частотность основана на корпусе субтитров, поэтому список ориентирован прежде всего на разговорную лексику и содержит словоформы, имена и отдельные редкие элементы.
- Словарная проверка не понимает контекст так, как нейросеть; она сравнивает введённый перевод с сохранёнными вариантами.

## Публикация на Netlify
Архив можно загрузить через Netlify Drop. Серверные функции, переменные окружения и API-ключи не нужны.

## Установка на телефон
- Android: Chrome → меню → «Установить приложение».
- iPhone: Safari → «Поделиться» → «На экран Домой».

## Источники данных
### Частотность английских слов
FrequencyWords, список на основе OpenSubtitles 2018.
Содержимое распространяется по лицензии CC BY-SA 4.0.

### Англо-русские соответствия
MUSE bilingual dictionaries, Facebook Research / Meta Research.
Словарные данные распространяются по лицензии CC BY-NC 4.0.

Итоговая база отфильтрована, отсортирована по английской частотности, сокращена до 15 000 статей и преобразована в компактный JSON. Используйте её для личных некоммерческих учебных целей и сохраняйте файл `DICTIONARY_NOTICE.txt` при распространении.
