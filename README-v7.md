# My English Dictionary — v7 Full Editor

Что изменено:
- В разделе «По урокам» у каждого урока есть кнопка «Редактировать».
- Можно менять номер урока целиком.
- Можно менять английское слово и русский перевод.
- Можно добавлять новые слова прямо в существующий урок.
- Можно удалять отдельные строки из урока.
- Можно удалять урок целиком.
- Можно редактировать счётчики правильных/неправильных ответов.
- У каждого отдельного слова есть кнопка ✏️: можно изменить слово, перевод, номер урока, статистику и дату создания.
- Загружены данные из пользовательского файла `Ингл.json` (20 слов).
- Если на устройстве уже были локальные слова, встроенные 20 записей аккуратно добавляются один раз без очистки существующих данных.
- Кэш PWA обновлён до v7.

Файл `preloaded-user-data.json` — точная копия загруженного пользователем JSON.
