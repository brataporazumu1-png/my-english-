# My English v9

Изменения:
- В разделе «По урокам» все уроки при открытии страницы изначально свернуты.
- Нажатие на заголовок урока раскрывает/сворачивает его.
- В приложение встроена резервная копия от 27.09.2026.
- При первом запуске этой версии данные из встроенной копии обновляют совпадающие записи по ID и добавляют недостающие.
- Существующие пользовательские записи, которых нет в копии, не удаляются.
- Сохранено автоматическое приведение английских слов к нижнему регистру.
- Сохранён раздел неправильных глаголов.
